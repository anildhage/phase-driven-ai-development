# Contributing to Phase-Driven AI Starter Template

Thank you for considering contributing to this template! 

### How You Can Contribute
1. **Improve AI Rules:** Refine `.cursorrules`, `.clinerules`, or `CLAUDE.md` to improve AI model compliance during phase execution.
2. **Enhance SDLC Mental Models:** Suggest updates to `development-in-phases.md` or prompt templates in `prompts/`.
3. **Bug Reports & Ideas:** Open an issue if an AI assistant struggles with specific phase transitions or instructions.

### Pull Request Process
1. Fork the repository and create your feature branch (`git checkout -b feature/improved-prompt`).
2. Commit your changes with clear descriptions (`git commit -m 'feat: update clinedirectives for better package resolution'`).
3. Push to your branch and open a Pull Request.
